# 整册 Blender 制作与网页复核

Windows 制作工程位于 release/Blender。打开“地球现场_整册模型.blend”后可切换六章 63 个场景。每页模型有独立相机，合计 4,956 个可编辑网格对象。模型从教材运行中的一次暂停导入，分支和连续动画继续由网页源工程驱动。当前范围覆盖 60 个原演示和 3 个综合扩展。主体轮廓、材质与动作仍要逐页复核。

[Blender 图版一](Blender全册-1.jpg) · [Blender 图版二](Blender全册-2.jpg) · [Blender 图版三](Blender全册-3.jpg)

本机使用 Blender 4.5.4 LTS、Cycles、OptiX 和 RTX 5070 Ti Laptop GPU。重新打开整册文件后验证所有场景及外部资源，并渲染全部 63 张图。Blender 内保留材质、剖面线、等值线和采样时刻的流程线。图版可用于构图、轮廓与部件审查。浏览器的墨线和纸张动画仍以实际运行画面为准。

网页生产入口 index-BnRguJOG.js。整册共用的仪器环境由 Blender 反射棚生成。左侧暖窗、冷填光、窄亮条与遮光板提供金属反射基准。地下喀斯特页使用同一岩壁模型生成的 1024 × 512 表面贴图与低密度起伏网格。前景石钟乳和石笋保持三处滴水落点。二维同步使用滴水释放、到达与沉积的状态。

桌面 63 个入口已遍历。密度天平、地下喀斯特和 GIS 分别采样 3、18、18 个状态。599 项单元测试通过。下一批优先检查台风眼墙轮廓、震后综合推演的节点尺度和岩溶切面的前后材质衔接。学生端发布与 Blender 制作工程分开存放，离线教学无需单独安装 Blender。
