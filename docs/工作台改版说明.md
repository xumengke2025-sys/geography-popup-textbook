# 工作台改版说明

## 当前交付补充（2026-11-06）

连续进度沿用同一份场景状态：选项可定位到过程节点，播放或拖动时同步更新模型与当前旁注。保留原教材底页、上方立体几何、纸签和木桌，不增加独立状态页面。不同地貌或实验条件仍保留为选择，其内部再按过程观察。

本轮实际查看60个镜头停稳、旁注已出现的桌面代表画面。溶洞和海冰排盐暴露了另一类可读性问题：文字矩形不相交，也可能被岩体或冰块挡住。因此只把这两处标注移到实体之外，以标签表面射线和四视口画面复核，没有把所有标签设成永远覆盖模型。太阳辐射改为可拖动的同一束等宽光，连续改变球面照射范围；观察纬度、实体、二维与当前说明共读同一状态。具体科学条件、构建及验证边界见验收记录。

城市雨水、寒潮与卫星定位采用可追踪连续过程，原有昼夜、海蚀崖等进度保留。旁注预留稳定空间，当前解释才淡入，拖动时不反复重排镜头。最后一轮遍历60个桌面与手机入口，修正寒潮小字、盐度重复标题、GIS中途标题重叠；寒潮两个冷暖标签另经四种视口连续取样复测。边界、构建与报告见 [验收记录](验收记录.md)，这些画面检查不是用户已认可整册审美。以下各段保留各轮设计原因及历史证据。

## 深度与地形的连续观察补充（2026-11-06）

海水温度、等高线地形与救援／恢复现在也沿同一条进度观察，原页、书本和工作台保持。海温探针、切片、曲线读点和旁注读取同一个深度；连续读数即时更新，解释段落改变时才淡入，避免播放中反复闪动。坐标与单位错开，重复图注收进模型说明。等高线点位字放大，高差标题避开甲乙标记。

进度含义按内容区分：海温是观察深度，地形是由平面到立体的观察方式；搜救与异地重建保留两个独立案例。太阳系和内部圈层增加读取生产模型坐标的原生SVG，切换二维保持条件与暂停。具体画面、专项结果和设备边界见《验收记录》。

## 同一场景的连续变化补充（2026-11-06）

继续使用原书、原页和工作台，增加海流、供热及台风的同一场景连续观察，不另建状态页面。快捷节点、实体点选、纸签和底栏进度驱动同一份状态，旁注只换当前阶段。供热二维设备现有点击和键盘入口；没有为入口额外加一排标签。

实看桌面供热、台风、海陆风，1024宽海流及390宽二维供热。原教材在下方，模型占上方空间；二维只作为阅读和降级形式。旁注固定预留高度，避免进度变化让模型在拖动中移动。实际检查与未覆盖设备见《验收记录》；当前画面判断不代表用户已认可整册审美。

## 连续过程交互补充（2026-11-05）

本次沿用用户明确提出的交互关系：把同一现象的状态并入连续过程，选项作为可选择的进度节点；模型变化时，旁边仅浮现对应说明。正文仍以原教材为底。这个反馈适用于同一个过程；不同地貌类别、盐度条件及滑坡／泥石流不因此变成必经的演化。

海陆风、潮汐、河曲和 GIS 的选项现在是同一过程中的快捷节点，海蚀崖内部增加四个形成过程节点。点击节点沿模型输入平滑定位，播放时阶段选项自动高亮；直接拖动时间轴则立即暂停。旁注只显示当前阶段的短解释，科学结论直接读取现有生产模型。桌面优先放在模型旁，空间不足时放在上方并预留显示空间；打开目录或快翻时让出位置。

受热、热力环流、遥感本轮也加入同一套机制：短波抵达地面后留下箭带，地面受热后再发出长波；同一剖面逐步出现冷热、升降、同高气压和环流；遥感中的同一批样本经过获取、传输、整理，最后组成影像并保留。实际几何与二维SVG共用纯模型，模型对象和前缘纸签可直接定位进度。

大气分层与森林成层沿用一个完整剖面，进度改变观察位置，全部层体持续保留；水循环则用同组六个示踪符号连接蒸发、输送、凝结、降水和返回。三类循环是独立条件，各自提供连续讲解节点。原生SVG读取相同坐标和派生状态，二维切换不另播一段动画。

实际平板尺寸拖动发现：旁注长短变化会改变相机为顶部预留的空间，进而让拖动轨道在手下移动。因此同一过程的旁注现在先按当前字宽测量各阶段文字，再预留固定高度；阶段切换只换文字，相机保持稳定。这条设计用于需要精确指向实体的操作场景，不能从静态截图判断拖动是否可靠。相关失败证据留在 `work/vertical-water-20261105/first-run`，通过与否以最新绑定构建的报告为准。

本轮按实际画面修正平板实体标签偏小、手机页脚截断和短旁注改变高度后遮住二维演示边界的问题。文字测量、相交检查和画面实看分别记录；检测通过不代表用户已经认可整册审美。

原教材底页、Three.js 立体几何、原书翻页和工作台材质沿用。海岸其他形态、盐度条件、滑坡与泥石流等仍是独立实验，不为了连续播放而串成虚构的演化。键盘操作、减少动态效果、二维图与本地进度共用同一过程状态。本轮验证及未验收范围见《验收记录》最新补充。
