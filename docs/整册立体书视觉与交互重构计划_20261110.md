# 人教版地理必修一：整册立体书视觉与交互重构计划

版本：2026-11-10，全场景深化版。性质：待实施计划，不是完成报告。

## 1. 最终要做成什么

一本保留原教材底页、在书页上方展开真实三维地理教具的交互式立体书。封面固定为“人教版地理必修一”。翻开书时，先能读清原文；点到相关知识，剖面、地景或仪器从页上连续形成；操作实体后，学生能沿着同一个对象看到条件、过程和结果。

视觉参考以本机“AI机械图”的实体构造、精细材质、功能细节和连续摄影为依据，书本、翻页与纸面升起继续沿用 Every Joule 的方法。总体体验是“课本打开，地理实验在书上成立”：近看有结构，远看有轮廓，动起来有原因，暂停后仍能解释。

用户当前要求优先：整册、真实立体、画风一致、中文清楚、优雅且有趣的直接交互；少说明、不堆叠、不重复；项目整体改好之后再录屏。早期海陆风单课、重新排课文、预测挑战印章等方案不恢复。

### 1.2 当前状态与本轮起点

当前项目已经具备原教材书本、真实Three.js模型、同源SVG、连续进度、默认2×、目录及原页阅读等基础。需要改造的是整册造型、材质和展开的系统性，以及逐场景交互深度，不能把既有功能重新列为本轮新成果。

## 3. 全册共同视觉规则

### 3.1 固定注意顺序

第一眼看原页与升起的主体，第二眼看正在变化的部分，第三眼看当前一条短说明。只有用户需要时才打开模型条件、长解释和来源。默认不同时展示一圈名称、全部箭头、完整参数表和解释面板。

原页完整保留；立体观察时相机可聚焦模型，原文需要通过“一键读原页”切换到正视放大，不要求用户在倾斜整本书的远景下读完正文。

### 3.2 分工明确的材质与颜色

| 对象 | 目标质感 | 控制方法 |
|---|---|---|
| 书页、标签 | 偏暖纸白、细纤维、深墨字 | 纹理低对比，文字区域干净；原教材页面不重新调色 |
| 自然地景 | 岩土有厚度、海水有表面、植物有层次 | 使用地理语义色；体积由法线、断面、遮挡与光照共同形成 |
| 支承与操作件 | 少量黄铜、钢、深木、象牙色刻度面 | 功能件清楚、装饰退后；微切边只加在稳定实体上 |
| 科学过程 | 水路、气流、辐射、输送各有稳定图例 | 用路径、箭头、编号或纹理补充颜色；同种含义跨场景不任意换色 |
| 当前选择 | 细边、操作柄和局部亮度变化 | 可点击对象可以发现，未选中对象不持续闪烁 |

不把全体模型改成透明玻璃。空气主要通过开放剖面、少量流线和明确上下层表达；容器只保留必要侧壁，避免多层透明材质混叠和虚假的厚玻璃罩。

共享材质按“角色＋表现状态”缓存，粗糙度、纹理尺度和颜色空间统一管理。先用同灯光下的球面、细杆、曲面水、岩块、中文标签标定，再迁移全册；颜色相似不能充当材质验收。

## 4. 从书页形成到操作的完整体验

### 4.1 展开不再靠整模型压扁后拉高

统一分成“原页定位—构件形成—主体就位—过程活动”四段。建议基准总时长2.0—2.8秒，复杂剖层可适当延长；保持真实可见的中间态，不按全册固定一套时长硬切。

1. **原页定位**：轻提示入口与对应原文；原文不擦除、不重新贴一张仿教材图。
2. **构件形成**：轮廓从原页锚点引出；结构件沿转轴转起、滑入或在落点连续显露。物体自可见起维持合理体积，允许材质裁切或显现辅助，不允许完整模型突然替换。
3. **主体就位**：球壳、山体、土柱与仪器占据书页上方；投影和接触关系随动作变化，构件不悬空错位。
4. **过程活动**：待主体看清后再启动气流、降水或运动；科学进度保持独立，不因展开耗时改变初始条件。

原插图入口强调岸线、轴、剖面等对应关系；正文入口用页边标记指出概念来源，不虚构原书本来就有一幅模型线稿。允许模型展开范围超过原插图，但保护相邻正文和工具安全区。

收回严格反向协调：科学过程暂停、选择部位复原、活动部件归位、主体收回、最后翻页。快速导航采用最后目标优先与请求失效机制，不能遗留模型、重复收回或出现过时页面内容。

### 4.2 三种交互语法

- **过程型**：同一输入进度决定全过程。播放、回拖、节点按钮和实体手柄互相同步；拖动立即暂停，回拖得到同一状态。
- **条件对照型**：选择温差、植被类型、介质等条件。各条件保持可比初态；条件间不是虚构的前后演变。需要独立重放时明确回到相同初态。
- **结构观察型**：抽层、展开、选样、剖开、移动观察面。不添加没有含义的播放动画；按钮和进度标题说明它是“观察位置”或“展开程度”。

默认2×继续保留。倍速只影响科学过程推进，不加速翻页、展开、相机或标签淡入。一次性过程到末尾停住，结果留在原处；循环过程明确适用，如波动、公转和理想昼夜循环。

### 4.3 有趣的动作来自对象本身

优先操作风旗旁的日月柄、剖面上的探针、土层抽签、地图定位销、实验容器的降水口；鼠标移入或首次停留给一次轻提示。拖动中不再争抢相机旋转；触控热区可大于实体但不改变可见造型。

点选对象后，它的结构或结果应作出明确响应，而不是只弹一段文字。每个场景至少提供一项与知识有关的直接操作或部位观察；全部核心操作有DOM/键盘等价入口。

| `atmosphere` 垂直分层 | 地表低位断面、三层开放剖面、独立高度探针与曲线 | 拖探针时层位、曲线读点、旁注同源移动，切层不跳高度 | 高层不被工具挡住；温度趋势与同一曲线一致，层体不是三块玻璃砖 |

| `greenhouse` 保温作用 | 同一地表与可加入的大气/低云层，路径不过密 | 无大气、有大气、有低云独立对照；看地面向外损失的差异 | 逆辐射不产生能量，不画成玻璃盖完全困住全部热量 |
| `thermal` 热力环流 | 冷—暖—冷开放剖面，近地面与高空各一条同高比较带 | 地表冷热变化后，垂直与水平运动统一形成；点层看气压 | 环流闭合；同高比较清楚，不用上下“高低压”直接推垂直风 |
| `breeze` 海陆风 | 厚海岸切块、水面、风旗、日月柄、上层开放空气空间 | 一条昼夜进度；温差缩小时流线渐弱、旗垂，再反向；拖日月回看 | 气压/气流/旗子/冷热同源；零驱动力不残留强风；海陆不因镜头换位而互换 |
| `pressure-wind` 气压差与风 | 同高地景与两侧压力指示，操作点放在比较层 | 有差/同压对照，风旗与水平箭带一致变化 | 只解释理想水平分量；同压不暗示真实世界所有风都消失 |
| `wind-forces` 等压线与风 | 轻地图片、可读等压线、风矢量和受力矢量；定位销不遮图 | 选原有四条件，同图比较；点力名突出对应箭头 | 南北半球与摩擦条件不混淆；结构比较不强行连续播放 |
| `haze` 蓝天常在 | 同一城市、排放源、开放观测范围与风旗；污染示踪稀疏可辨 | 点烟囱/风旗从同一存量独立重放，已有污染逐渐迁出 | 减排不能瞬间清空；看得见排放、输送、滞留的不同作用 |

### 5.3 第三章：地球上的水（9项）

| ID / 内容 | 实体构造与画面 | 动态与交互深化 | 场景验收重点 |
|---|---|---|---|
| `water` 水循环 | 海—陆—山—地下水完整切块，天空空间足以容纳输送 | 三循环分别选择，同组六个示踪跨状态移动；点水体跟踪 | 蒸发到降水、径流的身份和路径可追踪；不把示踪数当真实流量 |
| `water-renewal` 水体更新 | 补给、取用和污染进入同一可读储水体，液位有固定参照 | 改供需条件看存量与可用性变化，接收口真实响应 | 水量与水质分开表达；局地可用淡水减少不等于全球水消失 |
| `temperature` 海温随深度 | 深水剖面、原曲线、可移动切片与探针 | 拖深度持续读同一曲线；焦点随探针，不让整柱猛然缩放 | 原曲线与读数对应；深度是观测位置，不能误作海水升降 |
| `salinity` 盐度 | 开口海水槽、固定盐示踪、太阳/降水/径流三输入 | 点输入重放同初态，水位与盐度趋势共同改变 | 蒸发只带水；盐不凭空产生或随雨消失；三条件不是一个连续实验 |
| `density` 密度 | 两个等体积样本与克制的质量比较仪，液面容积固定 | 一次只改温度或盐度，质量指示随模型改变 | 不暗中改变体积和压力；天平表达质量比较，不混为浮沉实验 |
| `waves` 波浪 | 有厚度的开放水槽，表面波形与追踪质点分层清楚 | 拖追踪点观察闭合轨迹，波峰向前，质点往复；可暂停 | 质点不随波峰一路走；循环连续，模型不穿槽壁 |
| `tides` 潮汐 | 水下地形、岸滩、潮位杆和浮舟，潮间带可见 | 拖潮位柄，水面/岸线/浮舟共同变化；节点定位同一过程 | 舟不悬空、不埋水；不输出真实港口潮汐预报 |
| `currents` 洋流 | 水面剖段、十二个有固定身份的水体符号与原位参照 | 点水体追踪净迁移，与原有往复参照比较 | 首末位置保留，不中途换身份或重生；不假装现实地理定位 |
| `desalination` 海冰淡化 | 半透明冰体、有限盐水通道、收集容器，离心结构有真实轴 | 原两种方法独立观察；冰/盐水分离后产物在接收端留下 | 仍有残余盐水；不添加“可立即饮用”结论；离心轴与旋转体一致 |

| `coastal-landform` 海岸地貌 | 岩体侧壁、浪蚀凹槽、原位平台与有限崩落块 | 凹蚀到失稳、崩落连续可逆；拱桥/海蚀柱/海滩独立看 | 崩落体落在坡脚且不消失；其他形态不是第一项的必然后续 |

| `karst-livelihood` 峰丛生计 | 峰丛、有限表土、地下通道、植被和坡地农业结构 | 条件独立切换，跟踪水与土的去向，再看利用方式 | 雨涝晴旱有地形依据；农业选项不被包装成经济收益保证 |

## 6. 三个综合扩展场景

扩展的作用是把已学关系连起来。先完成现有60项的共同基础，再接入综合场景；不通过复制旧场景、增加切换按钮凑成新内容。

### 6.1 流域联系：一滴水从山地到河口

- **锚点与入口**：水循环页、河流/三角洲页可跳到同一拓展，不新增伪教材页。标明“综合观察”。
- **空间**：一块贯通山地、坡面、河道、平原、河口和海洋的流域切块；边缘开一处地下水剖面，不用全部透明化。
- **记忆画面**：同一滴有身份的水离开山地，进入河道，携带的有限泥沙在河口落下，而山地—河口空间关系始终留在视野中。
- **交互**：点上游/中游/河口定位观察，拖一次降雨过程；点击水滴跟踪，点击河口查看沉积接收端。
- **时间尺度**：一次降雨迁移与长期地貌积累分开。观察按钮明确切换“本次水路”和“长期累积示意”，不能把山谷切深、三角洲生成塞进一场雨里。
- **数据与复用**：复用水循环、河流和三角洲的路径/沉积逻辑，建立共用流域坐标；不直接叠加三个旧模型。
- **验收**：源头/河道/河口连通，示踪身份不变；两种时间尺度清楚；回拖后水和沉积读取同一确定状态。

### 6.2 城市雨水：同一场雨，三条去路

- **锚点**：第五章问题研究97页；与原`urban-waterlogging`共用条件和计算，扩展的是可读范围及观察方式。
- **空间**：同一街区上部是屋面、道路、绿地，下部是土层、暂存体与管网，使用能打开的侧剖面；不并排重复三座城市。
- **记忆画面**：地面仍有积水时，打开侧面，能看见水被暂存、缓慢下渗或进入排水通道，去向不再隐藏。
- **交互**：打开/合上地下观察侧；跟踪原有同批雨水；三种地面条件从相同降雨重放。可增加“暂存接近容量”的示意对照，须有显式条件和计算约束。
- **数据要求**：每份示意水都有地表、暂存、下渗或排出归属；不输出未经标定的毫米雨量、管径或重现期。若要给数字须补外部依据并重新核验。
- **验收**：不重复建设原模型；条件切换不换城市布局；地下流向、接收端和剩余积水相互一致；改善不能被画成无限容量。

### 6.3 震后协同：看到变化，找到位置，核验通路

- **锚点**：遥感、GNSS、GIS与物资库相关原页共同指向一个拓展入口。
- **空间**：同一灾后地形上布置居民点、可能受阻的道路、接收终端和储备点，三层地图信息与实体地形对齐。
- **记忆画面**：影像先给出一处可能变化，定位把求助点落到地图，独立通信送达后，经过核验的道路才连成可见路线。
- **交互**：叠合影像/位置/道路层；选择证据查看来源；将一条“待确认”道路标记为“已核验可通行”后再比较路线。
- **关键状态**：影像发现线索、定位成功、通信成功、道路核验和方案选择分别保存；任何一项未满足时相应后果不能提前发生。
- **复用**：共享遥感样本身份、GNSS信息分段和GIS空间叠合，另建小规模确定性演示路网，不接真实调度。
- **验收**：未知道路不自动通行；定位不等于求救发出；图层对齐；不宣称实际救援最优路线或应急决策能力。

## 7. 工作台与阅读界面整体改造

### 7.1 桌面和书本

桌面提供安静的木纹方向和有限高光，布垫承托书本；书脊、封面压印和页块有真实厚度。纹理对比低于教材与模型，不用密集纹样抢主体。目录签、页角和底栏沿同一墨色、纸白、少量黄铜与朱红体系。

封面只保留书名与必要的开始/继续入口，不增加副标题、营销说明或能力标签。合上与打开都应有连贯的书脊、页块和阴影关系。

### 7.2 导航与工具

| 元素 | 行为与造型 |
|---|---|
| 目录 | 按原教材6章17节及问题研究组织，显示当前定位；可查看本节演示，不在书页上铺开60个卡片 |
| 章签 | 细长、低对比；当前章一处强调，点击后保留清楚的返回位置 |
| 页角/快翻 | 页角反馈真实；快翻显示印刷页码和缩略图，原页序保持 |
| 主工具条 | 播放/暂停、统一进度、2×、收回为常驻核心；视图与次要操作收进一处，不重复出现 |
| 条件选择 | 只列本模型适用条件；长选项不无限挤成两三行，窄屏可横向选择或进入简洁选择面板 |
| 旁注 | 当前一步一条，优先1—2句；固定在安全区，不围绕主体漂移；长解释主动展开 |
| 部位观察 | 选中真实对象后出现对应入口；近看与返回整体成对，不增加无意义仪表 |
| 原页阅读 | 一键正视、适宽、整页及缩放；保留原页清晰度，退出回原模型与进度且暂停 |

桌面实验模式下主体目标约占可用模型区域的55%—70%，需按球体、狭长剖面、低矮地形分别调整，不能把整册统一放大到同一包围盒。关键操作与视线避开底栏、章签、旁注和原页阅读按钮。

### 7.3 中文与设备

主要控件、模型关键标签桌面目标不低于18 CSS px，投屏主要提示不低于28 CSS px，触控目标至少44×44 CSS px。原页以放大阅读保证可读，不在三维远景强行宣称正文达到18px。

标签是短词，说明是短句，条件和来源进入按需面板。标签锚定实体，必要时移到屏幕侧边并连线；不允许为始终可见而全局关闭深度测试，导致后侧文字穿过前侧实体。

横屏平板保留三维与触控；手机默认原页阅读＋原生SVG核心实验，性能允许且用户主动选择时再看三维。手机二维必须维持相同条件、进度和答案含义，不用视频替代交互。竖屏录屏可对三维产品专门取景，但不等于已完成真实手机WebGL验收。

### 8.1 保留和新增模块

| 层级 | 文件与职责 |
|---|---|
| 原书外壳 | 保留`textbook-book.ts`及原作适配；修改只围绕材质接入、展开协调、命中与相机 |
| 场景入口 | `textbook-catalog.ts`、`textbook-catalog-additions.ts`保持现有ID/页码；新增拓展清楚区分origin与来源 |
| 材质角色 | 扩展`textbook-visual-theme.ts`，新增独立材质工厂，按paper/rock/water/plant/brass/steel/wood/ivory等角色创建 |

| 装配配置 | 复核`textbook-instrument-profiles.ts`草稿；每ID有家族、组件、支承、操作区、展开轨迹与运动包络 |

| 工具界面 | `textbook-workbench.css`、`textbook-timeline.css`与主入口；先核对已改两文件，不盲目叠加新样式 |

### 8.2 科学、装配、观察三种状态必须分开

```ts
type SceneState = {
  scientific: { phase: number; selection: number };
  assembly: { reveal: number; stage: 'page' | 'forming' | 'ready' | 'closing' };
  observation: { target: string; view: string };
};

interface SceneAssembly {
  setReveal(progress: number): void;
  getSolidBounds(): Bounds;     // 不含标签与装饰性示踪
  getMotionEnvelope(): Bounds; // 含抽层、手柄、公转等合法运动
  dispose(): void;
}
```

这里的类型是计划契约示意，正式实现与现有类型体系协调。不能让装配控制器通过改科学`phase`模拟展开，也不能在科学update后覆盖其最终坐标。

推荐层级为“页框架 → 整体落位 → 装配组 → 科学部件 → 几何”，标签单独管理。科学部件先得到自身最终姿态，装配只作用于外层；观察用的抽层若改变视觉位置，需单独变换组，不修改科学位置或记录。

### 8.3 两个必须先解决的兼容点

1. **原Popout与PBR表面**：现有`addSurface`与`_surfaces`为原纸面材质服务，不能假定Standard材质自动支持相同uniform。先建立表面注册适配，明确线稿、显现、阴影、深度、收回各阶段如何工作；裁切若用于显现，阴影深度材质也必须使用同一裁切规则。保留原管线作为可回退基线。
2. **父级pivot与包围盒**：现有局部matrix测量不能覆盖新增父pivot。测量与轮廓须在统一的模型根坐标中计算，更新worldMatrix后转换回根坐标；排除标签，另算所有合法动作的包络。射线命中、标签锚点、轮廓和摄影必须用相同层级变换。

支承件只依附真实实体下缘或稳定轴足，不依据含标签、空气箭头或日月轨道的大包围盒生成巨型底座。GIS定位销避开图层升降路径；土柱夹座避开抽层；地层托架避开双柱间距；海陆风低位托角避开环流与日月柄。

## 9. 灯光、摄影与运动细节

主光方向全册稳定，软阴影表现地形起伏和构件间隙；补光只保证阴面可读。海陆风昼夜只改变模型内部提示与有限环境贡献，书页不能跟着变暗到读不清。金属靠表面反射与微切边显体积，不靠金色贴图和强泛光。

摄影提供阅读、整体实验、部位/剖面三个层级。展开时位置与注视点一起缓动，跟真实展开进度，不用独立计时器；学生开始拖拽时停止自动运镜。操作完成保留短暂静止，让结果有被看见的时间。

避免用同一三分之四视角强套所有模型：河曲/地图用偏俯视，空气/土柱用剖面，球体/森林用三分之四。进入近看时保证参照物至少保留一个，退出时恢复原观察方位，不能突然切换海陆左右。

较大移动使用速度与加速度平顺的曲线；运动到达不弹跳，工具反馈可以轻微。减少动态模式直接到达合法目标，仍保留全部结构与状态说明。

## 11. 验收如何保证真正达到效果

### 11.1 覆盖与证据

迁移清单逐ID记录：页码、家族、条件数量、节点、部位操作、科学模型文件、三维文件、二维文件、形成轨迹、相机、安全区、截图/录制、当前结论。由catalog提取入口，公开条件与代码中的分支逐项对照，不能手写60个勾就算覆盖。

每个过程分支至少检查0、0.25、0.5、0.75、1及公开节点；每个结构选项检查完整/选中/复原；每个条件对照检查相同初态与终态。另对临界转向、剖层最大间距、潮位极值、图层叠合等真正危险状态加采样。有限采样不宣称覆盖全部连续帧。

### 11.2 逐场景可见的标准

- **立体**：主体有侧面、断面或可辨遮挡；材料和光照支持体积；转动少量角度仍成立。
- **形成**：原页锚点、部分构件、中间形态、完成形态连续可见；球/柱不被压成纸片再拉伸；无突然换图。
- **体系**：相同功能件有共同尺度和材质逻辑，不同自然对象有自己的形态；构件数量服务知识，装饰不包围主体。
- **文字**：当前必要短标签清楚，不相互覆盖、不被主体或底栏遮挡；原文可便捷进入清晰阅读。
- **交互**：可操作部位能发现；触控不误翻页；学生操作对象会导致可见且相关的变化。
- **因果**：输入、迁移、接收、结果彼此对应；一次性结果保留；解释、三维和SVG一致。
- **摄影**：不会钻入地面或壳体，不因小标签放大丢掉主体；手动观察可打断自动动作。

每项记录“技术检查”“实际看过的状态”“个人视觉判断”“用户反馈”四种证据。没有用户明确认可，不写成“用户已认可审美”。

### 11.3 功能与科学回归

复用已有确定性模型测试，针对PBR/层级/新综合状态补必要检查。重点验证：同输入同结果、正反拖动一致、倍速不改状态、教师不污染学生进度、重置保留应保留数据、翻页事务无悬空模型、刷新恢复但暂停、二维三维同源、原页放大返回不丢位置。

全册保留`docs/整册覆盖表.md`中的科学边界。尤其核对：同高气压、S波液体边界、海陆风临界转向、波浪质点与波形、物料有限与接收端、海冰残余盐水、不同地貌的独立分类、地震震后预警、GNSS与通信、GIS空间归属、综合场景的时间尺度和不确定道路。

### 11.4 设备与性能

- 桌面：Windows Chrome/Edge，1366×768与1920×1080；平板布局：1024×768；手机二维：390×844及更窄视口。
- 真实触屏平板、学校低配机、投影设备若未取得，明确列为未验收，桌面模拟不能代替。
- 保留高/中/低三档；低档先减少反射、阴影、透明层和示踪，再简化微细节，核心立体、展开与因果动作不取消。
- 初始预算沿用常态尽量≤120绘制调用、主体约8万三角形；按实际设备帧耗时决定调整，不为达预算隐藏必要结构。桌面争取50—60FPS，低档交互争取30FPS；这些是目标，必须附设备条件才可报告结果。
- 材质/纹理/几何复用；多次翻页、抽层、开关面板后资源不持续累积。记录加载后的稳定值与循环后稳定值，不要求缓存数必须回到零。
- WebGL丢失/重建、字体失败、存储失败、后台暂停、减少动态、离线请求隔离都需走实际流程。新材质不得新增远程依赖。

### 11.5 最终录屏

最后才安排30秒9:16。建议节奏：0—3秒真实翻开书；3—9秒完整的一次纸面到立体；9—16秒有因果的直接操作；16—24秒切入至少两种不同家族的剖开/输送/叠合；24—30秒综合场景与整本书收束。镜头选择以最终效果为准，不提前锁死具体场景。

至少一段保留未跳切的形成过程，混剪在动作节点衔接；运镜来自稳定相机轨迹，不在后期突然放大补救。音乐低于产品动作与理解节奏，不靠音乐掩盖操作空档。输出后完整正常速度观看并实际听音，另做解码与抽帧检查，两者分别记录。

## 12. 完成的判定与交付清单

必须同时满足：

1. 原教材与封面保持；全部60项现有场景及其分支完成实质改造，没有只改外框/颜色的漏项。
2. 三个综合场景有真正的三维、直接操作、同源二维和科学边界，接入目录与书本生命周期。
3. 用户能看清“如何从书页形成”，能通过操作看见过程和留下的结果，少量旋转后结构仍成立。
4. 目录、快翻、原页阅读、连续进度、默认2×、本地保存、教师隔离和二维降级保持可用。
5. 检查材料与最终构建对应，仍未验证的实体设备和科学审阅如实列出。
6. 源工程包、静态网站包、Windows离线包、教师/来源说明、全场景验收表均交付，最后另附30秒竖屏视频及可复用录制脚本。

本轮的核心工作量在60个场景的造型、展开和因果交互，而不是增加页面说明或用少量漂亮样图代表整册完成。
