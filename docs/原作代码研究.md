# Every Joule 源码接入记录

## 当前实现注记（2026-11-05）

当前页面入口是 `index.html → src/textbook-main.ts`，三维书本由 `src/textbook-book.ts` 管理。原作书壳配置为 `nSpreads: 67`，承载教材 PDF 第 2—133 页的 132 张原内页，包括印刷页1—124页（含附录）、扉页、版权页、目录及4张书末留白。原教材文字、插图和版式作为底页保留；当前版本有 60 个演示入口，其中 24 个来自插图、36 个来自正文，覆盖 17 节与 6 个问题研究的主要知识。逐项内容见《整册覆盖表》。

当前实现不再沿用早期三课的重新排版、预测、解释翻片、练习和印章流程。下面的早期追踪表保留研究过程，不能作为当前界面或验收结果的说明。

| 当前源码 | 实际适配关系 |
|---|---|
| `src/textbook-main.ts` | 目录、原页放大、演示控制、本地书签和笔记、教师状态隔离，以及翻页与演示的异步请求协调。 |
| `src/textbook-book.ts` | 直接使用原作 `createRenderer`、`createStage`、`createBook`、`Popout` 和后处理；保留书壳、纸面变形、翻页、纸面命中与底栏。教材页影像由 `drawPage` 绘入原作书页。 |
| `src/textbook-catalog.ts`、`src/textbook-catalog-additions.ts` | 原页与跨页映射、132 张内页、60 个演示入口、教材目录和各模型的简化说明。 |
| `src/textbook-illustration.ts` | 按内容构建独立几何，并继续使用原作笔触、纸面材质及 `print → peel → shade → live → undraw` 生命周期。模型根节点随展开进度真实上抬，并恢复竖向比例。 |
| `src/textbook-geometry.ts` | 提供实体、地形、剖面、线条、三维路径及短文字标签；连接原作 `InkLines`、`PenSchedule`、`inkBox`、`Popout.paper` 和 `addSurface`。 |
| `src/textbook-models-*.ts` | 宇宙、大气、水、地貌、植被土壤、灾害与地理信息技术的几何构建及变化规则。 |
| `src/textbook-coastal-world.ts`、`src/model.ts` | 海陆风的独立海岸地形、白墙灰瓦建筑、风旗与闭合空气环流；冷热、气压、风向和旗子读取统一模型状态。 |
| `src/textbook-pressure-world.ts` | 正文起源的 `pressure-wind` 演示：在原文上方展示同一水平面的气压差与风旗，不需要替换教材插图。 |

为避免第二幅投影画到原教材正文上，当前适配在 `TextbookIllustration.update()` 中关闭原 `flat` 影本，并将 `uCopyAlpha` 设为零；`erase()` 对上抬模型保留底页。保留的是原作几何描线与表面显现管线，取消的是会覆盖教材的复制投影。独立几何可超出原插图矩形，使用书页上方空间。

三维地景不接收教材裁图作为贴图。`PlaneGeometry + CanvasTexture` 用于短文字标签；旗布也使用可变形平面几何。这些用途与将整张插图贴成模型不同，不能把文字标签计作实体地景。

当前适配还修正了三处一致性问题：`TextbookGeometry.trace()` 对双点路径使用 `LineCurve3`，避免双点 Catmull-Rom 在起点短暂反向；北半球台风的近地面气流从上方看为逆时针辐合；`textbook-main.ts` 用请求序号使翻页后的过时模型请求失效，并与 `TextbookBook.closeFigure()` 一起通过共享 Promise 合并重复收回，避免异步模型留在已翻过的页面上。以上是实现依据，不代替真实设备的视觉与性能验收。

本轮在同一套原作书壳和 Popout 上扩展实体交互：`textbook-model-input.ts` 定义选择及昼夜手柄，模型只给真实 mesh 标记输入信息；`TextbookBook` 先按可见几何射线命中，再区分实体点击、日月拖动和场景旋转。日月用模型根坐标中的示意椭圆反算同一 `phase`，不另播一段昼夜影片；44 CSS px 最小抓取范围与初始抓点偏移只改善输入，不改变可见模型。圈层选择沿用封闭壳体、截面和轮廓的同一位移，不在表面添加整幅示意图。输入经 `onModelInput` 送回课程状态，暂停、保存和教师隔离继续使用现有逻辑。

本次续作将该契约扩展为 `phase-track` 和 `replay`。水滴在模型根坐标的前方轨道上拖动，射线投影后反算统一进度，并保留抓点偏移；拖动过程不转动相机。喀斯特直接修改同一岩体的顶点和表面水路，保持闭合岩体与固定缓冲；土壤由六层连续剖面构成，点击时只抽出一层，24 个固定物质标记随同一模型从淋溶层迁到淀积层并停留。灾害链使用实际水体、坡体与聚落；点井、滑坡体或回卷纸片从头重放所选情景。原生 SVG 读取同一状态，点击与键盘入口通过现有主入口回传，切换阅读模式保持进度并暂停。

本项目当前反馈的适用范围：用户要求原教材作为底页、模型使用书页上方空间、文字清楚且不堆叠，接下来的重点是动态与有趣的直接操作。因此交互优先使同一物体发生可追踪的变化、让结果停留，少加解释面板。该选择适用于本书的过程观察，不能推广为所有界面都应减少正文。用户明确认可过海陆风白天立体截图；新三项的自检与截图观察不写成用户已认可。

提取入口是 `scripts/adapt-reference.mjs`：从阅读稿 main.js 截取启动状态 `const qo` 之前的声明，导出原对象；给 stores.js 追加笔触工具导出；复制相应 JS 依赖。源码包已包含提取后的 src/reference，开发和构建不依赖研究缓存。重新提取需要原仓库与格式化阅读稿。

针对本课的改动：封面/书脊书名改为“人教版地理必修一”，长中文标题调整字号；中文使用本地字体；海陆风输入、流场、旗子、中文排版与练习由本项目编写；保留原作纸张、书壳、笔触、展开和胶囊的实现。UI 额外功能收进菜单，不再覆盖书本。

实际排查出的耦合：少于原版页数时总厚度不足以匹配固定书脊，纸页会沉入书壳；恢复十四叶而限制应用导航。异步字体就绪后，模型可能已被首帧隐藏，印刷前必须恢复几何可见性，否则初始纸面空白。这两处均在适配层修复。

扩展水循环与河曲时，没有另建模型展示系统。`GeographyPen` 包装原作的 `InkLines`、`PenSchedule`、`inkBox`、`Popout.paper` 与 `addSurface`，两个新场景仍经 `renderPrint → draw → live → undraw`。书本一次只显示当前课模型；离页保留学习状态，回页暂停。河曲的水面与岸线共用曲线和裁断参数，避免箭头已转入新河道、旧弯道却仍与主河连接的错误。缓存不变的阴影图，低档减少示踪数量与阴影分辨率；未替换书本或描线管线。
