当前 60 个演示包含 24 个插图入口与 36 个正文入口，一次只展开一个。正文入口的页边标记用于定位知识，不要求把模型限制在附近插图的框内。三维对象使用实际几何和原作纸面材质，不将教材裁图贴成模型表面；短标签使用文字纹理，教材原页本身使用页面影像。

展开仍使用原作 Popout 的描线、表面显现与收回管线，并由适配层抬升模型所在父组。原教材页下方不擦除文字或原图；原作印刷投影副本在此模式下隐藏，避免额外图案写入原文。翻页前先收回模型。摄影机提供整书与近景，标签朝向读者。

海陆风的冷热关系、气压标签、环流、风旗及二维图读取 `model.ts` 的统一科学状态。内部曲线为教学设定，不是气象实测；其他模型的时间、速度、厚度及路径也须按各自“模型说明”理解。项目未接入真实天气数据或预报服务。

二维模式使用独立的 SVG/HTML 呈现，演示区位于教材原页之外。当前 60 个入口均返回不含图片的原生 SVG，最后补齐海温、等高线、救援／恢复、太阳系与内部圈层。它们读取与三维相同的过程或观察状态，旁注也由该状态生成。原教材页面影像完整保留；二维向量形式与三维实体几何分别实现，不能由这一统计推断整册逐状态一致性或视觉验收已完成。

每个演示的控制项、循环或到末尾停止的播放规则由课程清单定义；三维与二维共用当前进度和选择。除海陆风等明确共用计算模块的部分外，不能仅因输入相同就宣称全部模型的两种表现已完成逐状态一致性验证。

本轮河曲和 GIS 分别由独立过程计算生成三维状态及原生 SVG。河曲把河槽变化、洪水冲颈和旧弯道淤塞连成连续过程，三个控件停靠到 0 / 0.6 / 1；GIS 把图层叠合和逐区计数按先后展开，两个控件停靠到 0 / 1，33 个站点按教材区界的点在多边形内归属得到 5 / 15 / 13。两项均播放到末尾停止。它们不是实际高程、侵蚀时间、地理测量或雨量数据。

太阳系保留纯相位寻址，改用首尾闭合的示意整数圈数，不声明真实公转周期比例；地球圈层按层统一处理球壳、内壁、截面、轮廓及聚焦标签，拉开时保持原壳厚度。水循环的细雨向地表或海面下落，落速与数量仍为示意。上述局部修复不改变教材原页，不据此声称所有演示已经完成过程与视觉精修。

本轮污染使用固定示踪池区分已有污染与后续新增，三项条件从相同初始存量开始。通风改变移出观察范围的速度；减排只减少后续新增，不删除已有污染。三维合批示踪与原生 SVG 共用 `evaluateHaze`；烟囱、排放短标签、风旗及通风短标签是模型点选入口，底栏提供相同选择。切换到不同条件会从头重放，不能把画面切换解释为现场瞬时净化；不计算 AQI、真实排放量或治理天数。

三角洲使用固定颗粒池，将搬运、河口减速、下沉与落下后保留连成连续过程。沉积床面由颗粒沉降状态推导，不再独立缩放一张扇形；三条分流为不等长弯曲路径，三维与二维共用 `evaluateDeltaDeposition`、路径和沉积关系。形态、高程及沉积厚度为示意与夸张，不代表普遍三角洲形状、真实岸线、水深或沉积速率，也未模拟波浪、潮汐、河流输沙与相对海平面的完整共同作用。

成土因素保留原四项，第五项“地貌与颗粒”采用固定 54 颗粒与三条顺坡水路。位置由进度纯计算，粗颗粒较早停留，细颗粒继续搬运；水流退去后终点分布保留，正反拖动不依赖播放历史。三维与原生 SVG 共用 `evaluateSoilSorting`。它只是水流搬运分选的一种示意，不覆盖全部成土因素，不把内部量标作真实侵蚀或成土速率。

地震构造与新增预警视图共用 `evaluateQuake`：地震先发生，P 波到监测站后经过处理才发送通信信号，再比较预警与 S 波到聚落的先后。远处与近处示例使用同一探测和处理规则，近场可能没有提前量；三维与原生 SVG 共用事件状态。内部距离、速度及延迟只构成可回拖的教学时序，不显示真实秒数或预测震级。通信与地震波分别表现，震后预警不等于震前预测，模型不提供真实告警服务。

盐度三项共用 `evaluateSalinity`，从同初始海水与固定溶解盐量开始，以有限水量份额区分源头、途中、海水内和已移出；蒸发不携盐，降水和径流按淡水补入。水面、盐度趋势、三维水量标记与原生 SVG 读取同一状态；金色标记表示溶解盐，不是沉淀盐晶。太阳、雨云与河流可重放各自试验，水滴轨道可暂停回看。内部量无实测单位，不求解完整海洋收支、温度或密度。

海岸第一项共用 `evaluateCoastalProcess`，将崖脚凹蚀、上部失去支撑、三块有限岩块断裂崩落和原位平台露出连成可回拖的过程；岩块不会在终点删除。实体几何与原生 SVG 读取相同岩块姿态和凹蚀状态，纸签只控制教学进度。另三类海岸地貌保留为独立观察，不是必经后续阶段；岩性强度、侵蚀速率和地质年限未标定。

地层共用 `evaluateStrata` 与固定化石矢量形态，将六层岩体、九个浮雕化石及各自轮廓按所属层一起移动。`selection` 的 2—7 表示六层焦点，顶栏仍只有“同时代地层／分层查看”两项；相同组合对应 A 下层与 B 中层、A 中层与 B 上层，另两层不虚配。纸签只调教学展开间距，不表示等时长；原生 SVG 支持实体与化石点选及键盘焦点保留。未见对应不推断当地缺失该时代，也不以重绘形态鉴定物种。

滑坡与泥石流共用 `evaluateLandslide`，分别处理沿滑动面运动的连贯滑体，以及沿沟道下行、在坡脚展宽的有限含水碎屑。两项切换从各自初始条件重放，实体或回卷纸签可重放当前项，过程轨道暂停回看；物料在终点保留，原生 SVG 读取相同状态。两项不是同一灾害的连续阶段，没有求解降雨触发、真实失稳阈值或现场影响范围。

当前页面由 `index.html` 加载 `src/textbook-main.ts`。旧 `main.ts`、`scene.ts`、`paper.ts`、`state.ts` 等三课模块仍在源工程中，但不是当前页面入口；旧预测、练习、印章和观察报告流程不属于当前界面。

保存键为 `pep-geography-first-original-v2`，包含书签、演示条件、笔记、画质与减少动态效果偏好。教师模式使用学生状态的独立副本，退出后恢复；无账号、云同步或在线模型调用。原页为栅格影像，放大阅读尚不等于完整文本无障碍。
