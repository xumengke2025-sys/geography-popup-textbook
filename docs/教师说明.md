# 教师说明

本版保留人教版《地理 必修 第一册》的 132 张原内页，以 67 个跨页位置阅读；提供 60 个可展开演示，覆盖 6 章、17 节和 6 个问题研究的主要知识。模型在教材上方形成独立立体空间，正文、原图和图注仍是阅读依据。

每节、每个问题研究有演示入口，不等于每句话、每幅图、每道活动题都有动态模型。演示是帮助学生看清空间结构、条件对照和过程联系的教学示意；不能由演示数量推断学生已经理解，也没有公开课堂效果数据。完整入口、页码和二维形式见 [整册覆盖表](整册覆盖表.md)。

## 连续进度的使用

昼夜、海蚀崖和其他形成过程沿一条进度变化，节点是快捷定位，点后暂停；拖动立即暂停，旁注只解释当前变化。城市三种地面仍是独立条件，切换会从同一场示意雨重新观察；12个水标记数量不是降水量或分配比例。排出的水停留在收集池，土中与地表水也保留去向。寒潮只演示同一地点在冷空气前缘过境后降温与风的联系，不按温度阈值判断真实寒潮。GNSS接收位置与求救发送分开，通信设备须具备发送能力；监控到定位的推进是讲解顺序，不是每次定位的强制流程。

## 课堂操作

本地服务启动后可直达 [海陆风立体演示](http://127.0.0.1:4173/?figure=breeze&3d)，链接末尾加 `&play` 即开始连续观察。

1. 点击封面打开；左边的红色“目录”书签可查找教材章节或切换到“立体演示”索引，桌面右侧六枚章签可直达各章。点击底栏页码打开原页缩略预览，拖动只预览，点击缩略页或“翻到这里”才翻页；也可直接输入正文页码。点击纸面播放标记展开对应模型。正文入口位于相关段落页边，不要求原段落先有插图。
2. 展开后用底栏播放或暂停、拖动进度、选择条件。拖动进度会暂停，松手后保持当前状态；收回后重新展开已访问模型也保持暂停与原条件。拖动立体场景旋转，滚轮缩放；展开后先近看模型，“整本”用于对照教材，“近看”返回结构视图。
3. 右上角“原页”打开原页大图，支持缩放、左右逐页阅读；窄屏可用目录中的“放大左页／右页”。需要原文时使用此入口，不必在三维全景里读小字。
4. 右上角“授课”切换教师演示。它从当前个人状态复制一份临时演示状态；教师的翻页、条件、笔记与显示偏好不覆盖个人记录，退出后恢复个人页面、条件、画质与减少动态设置，并暂停播放。授课时不能清除个人记录。它不是班级管理或远程授课功能。
5. 点击“收回”再对照原图；翻页也会先收回当前模型。目录中的笔记可打印当前原页和笔记。

书面区域的左右方向键或 Page Up／Page Down 可翻页；滑块、输入框和选择框内的方向键用于当前控件。Tab 可进入页面按钮，按钮上的空格执行该按钮，目录标签上的左右键切换目录类型；焦点在书面且有活动演示时，空格切换播放。Esc 先关闭当前目录、缩略预览、说明或原页阅读，再可收回模型。设置提供画质及减少动态效果；减少动态效果时可直接观察目标状态。

部分演示是逐步发生的过程，到进度末尾停止；“重放”让进度回到起点，通常保留当前对照项，海陆风和潮汐同步到各自起始阶段。其余循环演示会反复播放。切换条件并不总会重置进度，做对照时可先暂停在同一位置再切换；污染对照与喀斯特六种形态会从各自初始状态重放。三维与二维之间切换保持进度并暂停。进度滑块不统一代表真实天数、年数或发生概率。

河曲的“河曲 / 洪水冲颈 / 牛轭湖”分别定位到教学进度 0 / 0.6 / 1；GIS 的“图层分离 / 叠合统计”分别定位到 0 / 1。点击这些停靠按钮会定位并暂停，点击播放观察连续过程；两项到末尾均停止，拖动滑块可回看中间状态。

电脑窄窗口仍默认立体；仅当可用宽度不足 600 CSS px，且设备以触摸为主、不支持悬停时默认二维。地址中的 `?2d` 可指定二维阅读，`?3d` 强制尝试三维；WebGL 不可用时仍降级二维，也可在目录中切换。

二维演示显示在原页上方的独立区域：60 个均为原生 SVG。海温、等高线、救援／恢复以及太阳系、内部圈层已补齐同源向量表现；三维和二维读取相同过程或观察状态。二维形式不等于三维模型的截图或完整替代；具体名单见覆盖表。原页是图像，放大阅读尚不等于完整可搜索正文或屏幕阅读器正文。

书签、条件和笔记只保存在当前浏览器。教师模式的临时记录退出后不保留；浏览器拒绝存储时仍可使用，界面会提示临时会话。打印入口输出当前跨页原页与笔记，没有自动成绩、观察报告或完成印章。

## 观察深度、地形与恢复案例（正文 3、22、50、77、111 页）

海水温度：探针连续定位表层至约5千米，水体和温度曲线固定。曲线是图3.8单个观测站印刷图的近似读图，不是新观测或全球海温。保留原坐标至6千米，但不把曲线外推至该刻度；旁注读数带“约”，进度不是降温时间。

等高线地形：同一三角网、贴地等高线和甲乙点位从平面抬起。甲879.0米、乙885.4米，高差6.4米；旁尺另作放大。模型保留原图的主要沟谷和点位关系，细部与未知高程作教学插值，不是实测DEM，辅助10米等高线间隔不解释成原图等高距。进度不是山地形成时间。

救援／恢复：图6.16玉树搜救与图6.17北川异地重建是两个地点、两个事件，分别选择，各自内部连续观察。不把搜救现场变成北川新城，不给出实测救援时长或重建进度。

太阳系与内部圈层的二维图读取原有三维坐标与抽层状态；示意公转首尾闭合但周期、距离、大小不按真实比例。抽层是观察手段，不表示地球内部实际分离。

## 连续观察补充（正文 9、61、103 页）

太阳辐射的纬度差异：上下拖动同一束等宽平行光，或点击低、中、高纬度节点，比较实际球面照射范围。光束截面始终相同，进度代表观察纬度，不代表一天或一年。模型固定太阳直射赤道，对照北纬0—65°各地局地正午的入射角；只解释一个几何因素，不计算第9页图1.12的大气上界年总辐射量，也不代表任意季节的纬度分布。

海水运动：拖纸签追踪同一组十二个水体，起点墨圈不动，末位置保留；点水体定位。小型往复参照复用波浪的同一质点轨道，用来区分往复与整体迁移。原图3.26是阿根廷东南沿海洋流交汇处浮游生物影像，没有方向箭头；上方模型为无地理定位的补充示意，不表示真实海岸、海温、速度或轨迹，也不模拟洋流交汇的生态过程。

家庭太阳能供热：在同一个剖面房屋中查看短波到达、集热受热、水路循环和室内供热。点太阳、集热器、水泵、散热器或拖纸签定位；光的菱形标记与已有水体标记分开，不把辐射变成水。图1.14的集热器不是图1.15的光伏板；共享储存池和水路是教学连接，不是设备安装图，也不输出实测温度、流量或效率。

台风：同一个成熟台风保持剖开的眼墙、空洞和云体，进度依次突出低层辐合、眼墙上升、高空辐散与眼内下沉，前面已显示的气流保留。点实体或拖纸签回看；这是观察顺序，不是成熟台风的形成时长或预报。旋转示意按北半球从上方观察，眼内以下沉为主，不表示实际台风眼始终完全无云。

## 新增的连续演示（正文 34、36、114 页）

大气受热使用一个地面剖面，太阳短波先到达地面，地面逐渐增温，再出现地面长波及近地面大气受热；前一步的箭带保留。四个选项定位同一过程，点太阳、地面、长波箭带或空气层也可定位，前缘纸签可连续回看。它突出图2.9主线，不量化反射、吸收比例，也不在这幅图添加逆辐射。进度是讲解顺序，不表示气象时间或能量数值。

热力环流使用同一个B—A—C剖面，从受热均匀、冷热不均到升降运动、同高度相对气压和完整环流。分别比较近地面和高空，暖侧A近地面相对低压、高空相对高压。垂直运动依据冷热与浮力解释；逐步显现不是实际大气中五段互不重叠的时期。点实体箭带、气压带或底栏节点可暂停定位。

遥感以图6.21的被动光学例子为依据：太阳照亮地物，反射光进入传感器；获取的信息传给地面接收站，经空间整理形成示意影像。十二个固定样本具有相同身份和图案，各装置中完成的副本保留。处理只演示按已知位置整理样本，不作自动分类或灾害预报；有源雷达不是本图演示的类型。可点装置或拖前缘纸签回看，末尾保留成果。

上述过程及盐度、土壤剖面、滑坡／泥石流和震后预警旁注随进度变化。条件选项保留各自含义；例如滑坡与泥石流仍是两个情景，土层选择只改变观察焦点。桌面优先侧放旁注，空间不足时预留顶部说明位置。

## 海陆风与风的形成（正文 36、38 页）

在正文 38 页展开“海陆间的大气热力环流”。场景保持陆地在左、海洋在右；可切换白天、夜晚，或拖动昼夜阶段。让学生对照冷热、两层气压、环流方向和风旗的同步变化，寻找环流减弱后转向的过程。

也可直接抓住模型上方的太阳或月亮，沿细虚线移动；小图标周围留有至少 44 CSS px 的抓取范围。从图标边缘抓住时保留原抓点偏移。拖动立即暂停，放手保持当前条件并保存；普通场景拖动仍用于旋转。日月及轨迹是示意时间控制，不是太阳轨道、方位或日出日落时刻的精确表示。

近地面暖侧相对低压、冷侧相对高压，高空关系相反。高低压只在同一高度比较；不能把垂直气流解释成“从地面低压吹向高空高压”。冷热响应有滞后，太阳落山不等于近地面风立即反向。

同页“大气的水平运动——风”正文旁的标记可单独展开同一高度的气压差模型。切换“存在气压差 / 气压相同”，比较水平气流及风旗。这里仅讨论水平气压梯度力的理想分量；气压相同不表示真实世界一定无风，地转偏向力与摩擦力需继续读下一页。

海陆风内部冷热曲线是无量纲教学设定，当前界面没有温差强度选择。它不显示实测摄氏度、百帕、风速或精确转向时刻。模型假设晴朗、背景风较弱，忽略复杂地形和大尺度天气影响；场景中的山地与聚落用于空间辨认，不是地形风计算。

地层与化石对比（15 页图 1.23）保留 A、B 两柱共六层和九个化石。点层体或化石，所选层与原图中具有相同化石组合的对应层一起向前抽出；再次点击同一焦点取消，仍保留分层。扇形与卷曲壳印痕组合对应 A 下层与 B 中层，长锥形印痕对应 A 中层与 B 上层。A 上层和 B 下层不强行配对，也不能由此推断当地缺失某个时代。分层模式可上下拖纸签调节间距；间距不是年代长短，印痕只是按原图可辨外形重绘，不鉴定具体物种。二维可点选，并用 Enter／空格选择或取消。

大气分层（31—32 页）保留一个三层立体剖面。上下拖动高度纸签，沿同一温度曲线观察读点，点层体或标签可平滑定位；高层气温曲线包含先降后升的变化。进度表示观察高度，不是气象时间；高度与温度未作实测标定，图顶也不是大气边缘。对流层以垂直运动为主、平流层以水平运动为主，不等于完全排除其他运动。

森林成层（83 页）保留同一片林地中的乔木、灌木与草本。拖动观察纸签可从树冠连续移至林下，相对光照提示和旁注同步；点植物或标签定位对应观察高度。植物没有随进度生长、消失或演替，观察面的上下移动不表示时间推移，光照与高度均为示意。

水循环（46—47 页）分别选择海陆间、陆地内和海上内循环，再拖动过程纸签追踪同一组六个示踪符号。海陆间循环区分地表和地下返回；六个符号到终点保留，不在画面中凭空重新生成。三类循环是独立类型，过程节点是当前类型内部的讲解顺序，不是现实中的固定分段时长。水汽不可见，菱形只作水汽示踪；云由凝结的小水滴等构成。示踪数、分流数和速度不代表水量、径流比例或降水量，终点暂停不表示自然水循环停止。

海水密度（55 页）可在等体积、同压力前提下分别改变温度或盐度；示意不代替实验测量。

海水盐度（52—53 页）保留蒸发增强、降水增多和河流注入三项，每项从相同初始海水与溶解盐量开始。可点太阳、雨云或河流重放相应条件，上下拖水滴暂停回看。先追踪水离开或到达海水，再比较水面与盐度趋势：蒸发不带走盐，降水和径流按淡水输入。金色标记表示溶解盐量，不是沉淀盐晶；水量、标记数和时长都是教学设定，没有模拟完整海洋收支、温度、密度或真实盐度分布。

波浪（57 页）可点击水质点突出其闭合往复轨迹，再直接拖同一质点或前方的进度手柄回看。波峰向前传播，所跟踪的水质点不随波峰持续前移；这是理想化波动示意，没有模拟破碎浪、真实水深、海流和漂移。

潮汐（59 页）可直接拖模型右侧潮位手柄，或使用低潮、涨潮、高潮、落潮快捷位。水面、岸线、浮舟与固定潮尺同时响应同一潮位；潮间带随露出范围改变。它不表示实际海岸的潮时、潮差或潮汐预报。

土壤质地（89 页）让三根不同质地的土柱接受同一场示意降雨。点选柱体查看，拖水滴控制进度，比较下渗、留存和底部出流；总水量按同一份计算记录，颜色与水滴数量不表示实测含水率或渗透系数。到末尾暂停，可点回卷纸片或底栏重放。

河曲与牛轭湖（70 页）可先停在河曲，播放观察洪水冲颈、新河道形成及旧弯道两端逐渐淤塞，再请学生指出牛轭湖与主河道的分离位置。过程是教材关系的一种可能示意，不表示每条河曲必然截弯，也不把进度当作侵蚀速率或地质年限。

海岸侵蚀与堆积（74 页）第一项“海蚀崖与平台”可拖动纸签，观察崖脚被浪蚀掏空、上部失去支撑、岩块断裂崩落，随后岸壁后退而平台留在原位。崩落岩块保留在坡脚，正反拖动用于检查同一次示意过程；重放回到起点。海蚀拱桥、海蚀柱和海滩仍是独立观察项，不是所有海岸必经的后续阶段；岩体强度、侵蚀速率和真实年限没有标定。

GIS 空间叠合（117 页）先把雨量站图层与行政区图层对齐，再逐区观察站点归属及计数。33 个站点与三区边界按教材示意图重绘，结果分别为 5、15、13；不是现实地理测量或雨量预测。请学生先说明“点落在哪个区”这一依据，再读最后数字。

太阳系（3 页）用首尾闭合的整数圈数呈现内侧较快、外侧较慢的示意公转，不代表真实公转周期比例。地球圈层（22 页）选择地壳或地幔时会把相应纸质壳体拉开，截面和轮廓随实体一起移动；选择地核时保留外核与内核。分离用于看结构，不表示地球内部实际张开，也不把模型厚度当作实测比例。

圈层既可用底栏选择，也可直接点实体截面或原有短标签：点地壳或地幔取出壳体，点外核或内核查看地核组，再点当前层复原。悬停仅加重对应墨线；按住拖动实体旋转视角，不会在松手时误选。

“何时蓝天常在”（43 页）可先观察“排放积聚”，再点烟囱切换“减少排放”，或点风旗切换“通风扩散”；再次点击相同对象返回原排放或微风条件，底栏也有对应选择。每次切换到不同条件从同一初始污染存量开始，正常动态设置下自动播放，减少动态效果时需手动播放或拖动进度。请学生分别追踪“已有污染”和“后续新增”：减排减少新增，已有污染不会立即消失；通风使示踪更快移出观察范围。三项是独立对照，不是城市在点按钮瞬间完成治理；示踪数量、速度和时间不代表 AQI 或治理天数，湿度、地表等其他影响没有完整模拟。

三角洲（71 页）选择“河口沉积”或“三角洲推进”，点“重放”观察颗粒先沿河流搬运，入河口后减速、下沉，落下后保留，沉积地形和岸线随过程展开。暂停后正反拖动可追看同一颗粒，比较较粗近、较细远的示意关系。三条分流采用不等长的弯曲路径，展示一种不对称河口；高程与沉积厚度为便于观察而夸张，不是真实岸线或水深，不表示所有河口都会形成三角洲或持续向海推进。

成土因素（91 页）的第五项“地貌与颗粒”依据 91—92 页山顶到低平地带颗粒由粗到细的解释，前四项仍可分别查看。选择第五项后播放，观察水流携带混合颗粒向下，粗颗粒较早停留、细颗粒继续移动；末尾水流减弱，颗粒分布保留。可暂停或反向拖动比较途中与终点。“山顶—山前—低地”只演示水流搬运分选的一种关系，不能由此概括全部地貌影响、所有土壤类型或真实成土速率；坡向、水热和其他成土因素仍须回原页讨论。

地震模型从 107 页保留震源、震中及深度关系，并联系 111 页震后预警案例。选择“震后预警”后点“重放”，依次观察地震发生、P 波到监测站、探测处理后发送通信预警、预警到达与 S 波到达；对照“近场对照”再重放，近处聚落可能在预警前已受到较强震动。也可点监测站进入预警视图，点聚落实体或聚落短标签切换远近场；这些点选保留当前进度，需要完整重看时再点“重放”。P/S 波与通信使用不同路径表现，预警不是震前预测，也不保证所有地点获得提前量；距离、波速、处理延迟与进度均为示意，不输出真实秒数、震级或现场应急结论。

滑坡和泥石流（108 页图 6.12—6.13）分别从各自初始条件重放：前者为连贯滑体沿滑动面整体下移，后者为有限含水碎屑沿沟道下行、在坡脚展宽堆积。可拖过程手柄暂停回看，点活动实体或回卷纸签重放；末尾停止，物料保留。两项是独立对照，不是同一灾害的前后阶段；模型没有求解降雨触发、真实失稳阈值或灾害影响范围，不能用进度判断现场危险或撤离时机。

## 六个问题研究怎样使用

地表喀斯特（66—68 页）可直接拖动前方水滴，观察雨水沿低处汇入裂隙、溶解并带走岩石物质，岩面只降低、沟槽逐渐拓宽。六种形态分别设有初始条件，切换时重放，不是所有地区的必经序列。模型不模拟真实溶液浓度、降水量或地质速率，地下碳酸钙沉积仍在另一演示中讲解。

土壤剖面（89 页）可点六层实体及出现的短标签，抽出当前层，再点复原。剖面保留原土壤基质，24 个示意标记只表示淋溶层中一部分可移动物质；先见雨水下渗，再见同一批标记下移、留在淀积层。可上下拖动左侧水滴暂停回看，抽层不改变科学进度。标记数量、层厚及进度不表示全部矿物质、所有土壤或真实成土年限。

灾害关联（108—109、115 页）可对照两条选定灾害链。旱灾分支选择沿海松软沉积层、地下水与海水连通、淡水不足后增加抽水的条件；地层压密和咸水入侵不由海平面上涨驱动。地震分支选择临河松散陡坡滑移堵河，上游来水蓄湖，并选定堰塞体溃决引发下游洪水。请学生先指出条件，再解释联系；不能说所有旱灾或地震都会如此。点抽水井、滑坡体或回卷纸片重放当前情景，底栏切换分支。
