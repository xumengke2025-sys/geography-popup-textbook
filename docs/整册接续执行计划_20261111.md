- 固定范围：60个原有场景、全部独立条件/结构部位/过程节点、3个已接入的综合扩展，共63个入口。综合扩展也要收敛，不能因已有入口就算完成。
- 固定产品：132张原教材内页、67个跨页位置；封面“人教版地理必修一”；目录/章签/页角翻页、连续进度、默认2×、原页阅读、本地保存、教师隔离、同源二维与低画质。
- 原作：继续Every Joule原书壳与Popout生命周期；模型在页上方真正形成，保留原页。装配进度、科学进度、观察状态独立。
- 不使用DeepSeek，不切换用户选择的模型；代理只处理明确不交叉文件，主线程统一构建、看图和验收。

## 2. 机械参考转成实际制作方法

已亲看`docs/reference/ai-mechanical/final-decoded-18.4.png`，读`scene.js`与本地`D:/ai项目/20261111_ai机械图/render-eighteenth.cjs`。内附源码与本地film-eighteenth SHA256相同：`bcb9c4e3caa0872621d0b5a109fdf7869def89529a4537cef5af5f0cce0c1b4a`。这说明参考版本一致，不表示已观看整部影片。

每件主体必须按以下顺序设计、建造、核查：

1. **主体与轮廓**：先画清楚地理对象、主轴/主剖面、工作区和运动包络。自然标本先有连续表面、断口与层次；仪器先有一条可追踪的工作轴。去掉五金后仍须能辨认题材。
2. **整件构造**：确定主体如何接到稳定承托，活动部件如何被约束、从哪里输入、在哪里接收。只在接触/受力/操作处使用台肩、孔、夹持与切边。禁止厚底板、细杆围栏和同款框架包住所有题材。
3. **动作先行**：输入—导向—接触—接收结果读同一状态；固定物质身份，结果留存，逆拖可恢复。展示装置不解释成地理成因。
4. **表面与光**：形体先成立，再处理曲率、法线、微切边、材料反光。参考的金属/木/象牙色只给对应物质；海水、土壤、植物保留自然身份。现有RoomEnvironment和PBR不是新完成数。
5. **页上形成**：构件保体积，按实际转轴/滑移/显现次序进入，完成后再启动科学过程；收回反向协调。剖层、球体和地景分别编排，不全册拉伸根节点。
6. **最终观看尺寸**：1440整体、1024整体、操作近景、形成中间态和小角度转动都要看。参考细节必须在书本场景里可见；不能凭放大的零件图称达标。

每批开工先给各场景写一句“整件主体是什么”和一条“输入到结果的路径”；没有这两项不增加细节。连续一批只能补五金而未改主体时，直接判为工程修复并转回主体问题。

## 3. 批次与推进节奏

先完成B0近期技术收口，再按下表推进。每批3—8项，以同类几何和因果链复用；已有合格专项主体只修真实短板，不从零重做。火星作为用户纠偏后的首件整机重构先行实施，归属B3，不能据此长期滞留该项。

|---|---|---|
| B0 技术收口 | GIS、森林/七类植被、火星、土柱/孔隙/质地/成土/水盐；灾害链旧包异常和生命条件遮挡 | 锁生产包指纹，确认近期改动的真实操作；旧失败在新构建复验，技术收口不算主体验收 |

B1—B13合计60原有＋3扩展，每ID唯一归属。详细分支与逐项主体目标见机器清单`handoff/reconstruction-manifest.json`及下方63项索引。十一种构造家族继续有效；上述批次是实施顺序，不强迫所有场景复用一套外壳。

**每批工作单**：当前源码入口与基线图 → 整体构造/动作草图 → 主体与分支实现 → 专项回归 → 固定生产构建 → 原生操作与形成 → 主线程实际看图 → 修复本批缺陷 → 台账与检查点。非必要不在每一小改后重复全量测试。

每批结束即进入下一批；共用缺陷在共用层解决，禁止复制13批修同一问题。阻断错误必须先修；非阻断瑕疵记录明确ID/状态，移入收敛队列。关键主体缺陷不得改名为“后期润色”绕过。代理完成不代表该批验收，主线程集成后才能提升状态。

## 6. 四类证据与版本绑定

每ID、每批均分别记录：**功能实现 / 测试通过 / 实际看图 / 用户认可**。新增“主体重构内容”描述实际改了什么，不以材质覆盖、mesh数、drawcall或截图数换算完成百分比。

- 技术证据必须包含生产JS/CSS路径与SHA256、源码状态指纹、浏览器版本、视口、条件/进度、错误、失败与未覆盖项。重建后旧证据保留为历史。
- 自动捕获的图只叫“已捕获”。主线程逐图查看整体、危险分支、近景与形成，记录看到的缺陷；其余图不能自动批量标“已亲看”。
- 主线程视觉达标是内部判断。用户认可只能来自明确用户反馈，默认`pending`，不新增强制等待审批流程。
- 当前目录没有`.git`，不伪造commit SHA；保留修改前文件、生成内容哈希与构建哈希。源码备份不能覆盖原始下载ZIP。
- 每约60秒报告新增事实、剩余问题与下一检查；每批及关键修复更新CHECKPOINT顶部。历史冻结停止指令已被当前用户接续授权取代。
