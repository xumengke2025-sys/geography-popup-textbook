人教版地理必修一 · 交互课本

本版保留132张教材原内页，提供60个立体演示，覆盖6章17节及6个问题研究的主要知识。原课本保留在下方，几何模型在书页上方展开；不表示每句话、每道活动题都已交互化。

1. 将整个 ZIP 解压到普通文件夹，不要直接在压缩包内部运行。
2. 双击“打开地球现场.cmd”。浏览器打开 http://127.0.0.1:4173。
3. 保留服务窗口；结束后关闭窗口。不需要联网、管理员权限或安装 npm 依赖。
4. 点击封面打开。底栏左右箭头、页角和方向键用于翻页；左侧红色目录书签可搜索章节与60个立体演示，桌面右侧章签直达各章。点击底栏页码可看真实教材缩略页、拖动预览、确认翻页，也可输入正文页码跳转。
5. 点击纸面播放标记展开模型。可暂停、拖动进度、选择条件；拖动场景旋转，滚轮缩放。“整本 / 近看”切换视图，“收回”返回原页。重新展开已访问模型保留条件并暂停，点击播放继续。
6. 海陆风沿同一条昼夜进度连续变化；选夜晚、日出、白天、日落会平滑定位并暂停，拖动进度也会暂停，旁边短说明随模型变化。海蚀崖的凹蚀、失撑、崩塌、平台也是同一过程中的节点。大气与森林拖纸签观察高度；水循环先选类型，再追踪同一批示踪符号。
7. 右上角“原页”打开原页大图，支持放大、缩小及逐页阅读；窄屏可用目录内“放大左页/右页”。二维演示单独显示在原页之外。
8. 右上角“授课”切换教师演示，教师操作不写入个人书签与笔记；退出后恢复个人页面、模型、条件与设置并暂停。
9. 右上角提供笔记与设置，目录内保留二维阅读及来源。笔记菜单可打印当前原页与笔记。当前没有挑战、印章或观察报告界面。
10. 使用同一浏览器和地址访问，书签、演示条件与笔记仅保存在该浏览器。“设置 → 清除本书记录”确认后清除；“重放”用于当前演示。
11. 进度条旁的“2×”是倍速按钮，默认2倍，点击依次切换4×、0.5×、1×、2×。选择会保留；只改变演示播放进度，翻页、模型展开和快捷节点定位保持原节奏。暂停时切换倍速不会开始播放。

启动后直达海陆风立体演示：http://127.0.0.1:4173/?figure=breeze&3d
在链接末尾加 &play 可直接连续观察。
电脑窄窗口仍默认立体；仅当可用宽度不足600 CSS px、设备以触摸为主且不支持悬停时默认二维。地址中的 ?2d 指定二维阅读，?3d 强制尝试三维；WebGL 不可用时仍降级二维。

如果4173端口已运行本项目服务，将复用；若被其他软件占用，会提示错误，不自动换地址。
电脑性能不足可在设置选择低画质或切换二维阅读；“减少动态效果”可简化展开动作。
模型都是教学示意：气流不表示实测风速，过程滑块不表示真实年数，图层间距不表示测量比例。展开后可查看“模型说明”。
