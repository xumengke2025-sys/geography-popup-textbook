# 自然标本与仪器木材的扫描来源

纹理随教材离线分发。Poly Haven 将下列实物扫描作为 CC0 素材发布。教材保留各土层自身的色相，并从扫描中提取漫反射明度、位移与粗糙度。岩土地表还单独保留漫反射照片中相对于本底的冷暖色差，近看可分辨土团、灰石和暗孔。可从制作脚本重新生成。 [CC0 说明](https://polyhaven.com/license)

| 教材用途 | 来源 |
| --- | --- |
| 土团、孔隙与有机土层 | [Brown Mud Rocks 01](https://polyhaven.com/a/brown_mud_rocks_01) |
| 裸岩、风化母岩与层理 | [Rock Face 03](https://polyhaven.com/a/rock_face_03) |
| 河岸砂砾与冲积物 | [Sandy Gravel](https://polyhaven.com/a/sandy_gravel) |
| 潮间带细沙与零星浅色矿粒 | [Sand 02](https://polyhaven.com/a/sand_02) |
| 带有地表覆盖的土坡 | [Forest Ground 04](https://polyhaven.com/a/forest_ground_04) |
| 仪器木座与握柄的胡桃木纹和细孔 | [European Walnut Veneer 04](https://polyhaven.com/a/european_walnut_veneer_04) |

地球剖面仪的着色球瓣按项目已有的 Natural Earth 1:110m 陆地轮廓绘制。经纬线、拼瓣接缝和纸面着色由 `scripts/art/paint-sectional-globe.py` 生成。[Natural Earth 公有领域数据](https://www.naturalearthdata.com/about/terms-of-use/)
