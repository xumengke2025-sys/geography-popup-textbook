## 打开与操作

启动后可直达 [海陆风立体演示](http://127.0.0.1:4173/?figure=breeze&3d)；在链接末尾加 `&play` 可直接连续观察。夜晚、日出、白天和日落是同一进度上的节点；模型、风旗和旁注一起改变，可随时拖动暂停或点节点回看。

本轮可直接试 [跟踪波浪中的同一水质点](http://127.0.0.1:4173/?figure=waves&3d)、[拖动潮位观察岸线](http://127.0.0.1:4173/?figure=tides&3d)、[比较土壤下渗](http://127.0.0.1:4173/?figure=soil-texture&3d)。默认直达暂停，可先操作实体或点击播放。

新增可直达 [大气受热](http://127.0.0.1:4173/?figure=heating&3d)、[热力环流](http://127.0.0.1:4173/?figure=thermal&3d) 和 [遥感信息链](http://127.0.0.1:4173/?figure=remote&3d)。底栏选项和模型上的对象都用于定位同一条过程，拖动前缘纸签或进度可以回看。

[大气分层](http://127.0.0.1:4173/?figure=atmosphere&3d) 和 [森林成层](http://127.0.0.1:4173/?figure=forest&3d) 现在各自保留一个完整立体剖面，拖纸签连续改变观察高度；所有层同时存在，旁注随观察位置变化。[水循环](http://127.0.0.1:4173/?figure=water&3d) 可连续追踪同一组六个水示踪符号的蒸发、输送、降水与返回，海陆间循环还区分地表和地下返回。三类循环仍为可切换的独立条件，各自内部有过程节点；示踪数量不表示水量。

[海水运动](http://127.0.0.1:4173/?figure=currents&3d)、[家庭太阳能供热](http://127.0.0.1:4173/?figure=sun&3d) 和 [台风剖面](http://127.0.0.1:4173/?figure=typhoon&3d) 现在也可连续播放、点实体定位，或拖动前缘纸签倒回观察；只显示当前阶段短说明。海流保留同一组十二个水体及起点，供热区分光与水的传递，台风是在同一成熟结构中分步观察，不是生成或预报动画。

[海水温度剖面](http://127.0.0.1:4173/?figure=temperature&3d)、[等高线立体地形](http://127.0.0.1:4173/?figure=slope&3d) 和 [救援／恢复](http://127.0.0.1:4173/?figure=mitigation&3d) 也接入同一进度。海温拖探针、切片或纸签，观察固定曲线上的不同深度；地形保留同一网格及甲乙高差，从平面抬起供观察；救援和恢复保留两个独立地点与案例。连续读数实时更新，说明段落改变时才浮现，避免播放时反复闪动。

- 点击封面打开，使用底栏左右箭头、页角或方向键翻页。左边的红色目录书签可搜索教材章节与60个演示；桌面右侧章签直达各章。点击底栏页码打开真实教材缩略页，拖动滑块预览、确认后翻页，也可输入正文页码跳转。
- 点击纸面播放标记或目录中的演示名称展开模型。底栏可播放、暂停、拖动进度和切换条件；拖动场景旋转，滚轮缩放，“整本 / 近看”切换视图，“收回”返回原页。重新展开已访问模型时保留条件并暂停，点击播放继续。模型说明默认收起，点击信息按钮查看。
- 海陆风把夜晚、日出、白天、日落放在同一条昼夜进度中。播放时模型、节点高亮、进度与旁边的短说明同步变化；点击节点平滑定位并暂停，拖动进度立即暂停。潮汐、河曲、GIS 也采用过程快捷节点；海蚀崖内部可定位凹蚀、失撑、崩塌与平台。减少动态效果时直接定位。
- 同一条过程中的所有中间状态都可以停下来观察。海陆风说明读取实际冷热和风向，不把日落等同于立即吹陆风。海蚀拱桥、海蚀柱与海滩仍是独立对象；盐度、土壤和灾害等保留各自条件对照。教学进度不统一表示真实时长或地质年限。
- 上一固定构建完成60个演示入口的条件与过程节点巡检，并修正风沙末态、水汽与杂质示踪、土壤水盐去向；本轮当前构建验证新增三类连续过程、五类原有进度回归、三角洲绘制及便携目录。教师隔离和WebGL丢失后翻页／恢复报告保留为上一构建基线。详细结果与设备边界见 [验收记录](docs/验收记录.md)，不以入口巡检代替整册科学与课堂验收。
- 海陆风可直接抓住模型上方的太阳或月亮，沿细虚线拖动昼夜。拖动会暂停并保留当前状态，冷热、同高度气压、环流和旗布一起响应；日月轨迹是教学时间控件，不是真实太阳方位。地球圈层可点实体或短标签拆看，再点同一层复原；拖动实体仍可旋转场景。
- “A、B两地地层对比”（15 页）可点六层实体或九个化石，所选层与有依据的对应层一起突出，再点同一层取消焦点；分层纸签可上下拖动调节间距。只保留原图两组对应，不给其余两层虚配；间距不表示年代长短，化石外形不作物种鉴定。
- “哪些条件影响海水盐度”（52 页）的三项从同一份海水开始；可点太阳、雨云或河流重放，拖水滴回看水量与盐度变化。蒸发只带走水，降水与径流补入淡水；金色标记表示不变的溶解盐量，不是沉淀盐晶。内部数量和比例不是实测盐度。
- “海岸侵蚀与堆积”（74 页）第一项可拖纸签回看崖脚凹蚀、上部失去支撑、有限岩块崩落与平台原位露出，崩落岩块留在坡脚。拱桥、海蚀柱和海滩是另外的观察项，不是所有海岸必经的后续阶段。
- “滑坡和泥石流”（108 页）可分别观察连贯滑体沿坡下移，以及含水碎屑沿沟道下行、在坡脚展宽停留。拖过程手柄回看，点实体或回卷纸签重放；切换两项从各自初始条件开始。它们是独立示意，不模拟真实降雨触发、失稳阈值或灾害范围。
- 河曲的“河曲 / 洪水冲颈 / 牛轭湖”和 GIS 的“图层分离 / 叠合统计”是进度停靠点，点击后定位并暂停。两项均可连续播放，到末尾停止；可拖动进度观察中间过程。
- “何时蓝天常在”（43 页）可点烟囱比较减排与原排放，点风旗比较通风与微风，也可用底栏选择。切换条件从相同初始污染存量重新播放；减排只减少后续新增，已有污染仍需逐渐移出观察范围，不能由按钮切换理解为立即清空。
- “冲积平原与河口三角洲”（71 页）可观察颗粒沿弯曲分流路径搬运、减速、下沉并保留，沉积地形随同一过程展开。三条分流长短与弯曲不同，代表一种示意河口，不代表所有三角洲的形态或真实沉积速率。
- “土壤形成的因素”（91 页）保留前四项，新增第五项“地貌与颗粒”：粗颗粒较早停留，细颗粒随水走得更远，终点保留分布。这是教材 91—92 页颗粒分选关系的一种示意，不是全部成土因素。
- “地震构造示意”（107 页）提供“震源与震中 / 震后预警 / 近场对照”。先发生地震、P 波到监测站，经过探测处理才发送通信预警；远处示例可能先收到预警，近处示例可能没有提前量。这是震后预警，不是震前预测。以上过程到末尾停止；“重放”保留当前对照项，从进度起点重播。
- “地表喀斯特地貌演变”（67 页）可抓住模型前方水滴，沿轨道拖动，观察雨水沿低处与裂隙进入，岩面下降、沟槽加深拓宽。切换六种形态会从各自初始状态重放；它们是独立比较，不是所有地区必经的等时序列。
- “森林土壤剖面”（89 页）先展示一整根六层土柱，点层体或短标签抽出，再点复原。左侧水滴可上下拖动，观察水先下渗，一部分可移动物质从淋溶层下移，留在淀积层；抽层不改变进度或物质数量。二维也支持点选与键盘。
- “自然灾害的关联”（109 页）保留旱灾和地震两项。前者在选定沿海情景中观察缺水、加抽地下水、松软层压密与咸水入侵；后者观察松散陡坡滑移、堵河蓄湖与选定溃决洪水。可点抽水井、滑坡体或回卷箭头重放当前情景，拖动进度回看。它们是有条件的联系，不是每次灾害的必然后果。
- 右上角“原页”打开原页大图，支持缩放与逐页阅读；窄屏可用目录中的“放大左页／右页”。全景中的原页会随书缩小，阅读正文应使用此入口。原页为图像，尚无完整可搜索正文或屏幕阅读器正文。
- 电脑窄窗口仍默认立体；仅当视口宽度不足 600 CSS px，且满足 `pointer: coarse`、`hover: none` 的触摸设备条件时默认二维。`?2d` 可指定二维阅读，`?3d` 强制尝试三维；WebGL 不可用时仍降级二维，也可从目录切换。60 个二维演示均为原生 SVG，太阳系、内部圈层、海温、等高线和救援／恢复已补齐。切换模式保持当前进度并暂停。演示区位于原页之外，与三维几何实现分别说明；原教材页面影像完整保留。
- 右上角提供笔记、授课和设置；目录内保留二维阅读和来源。书签、各演示条件、笔记和显示偏好保存在当前浏览器；教师演示使用独立临时副本，退出后恢复个人页面、条件、画质与减少动态设置，并暂停播放。授课时不能清除个人记录。地址或浏览器改变时，本地记录不会自动迁移。

本版以原课本阅读和立体演示为主，没有早期三课版的预测、挑战、印章或观察报告界面。笔记菜单可打印当前跨页的原页与笔记。教师演示不提供班级、账号或云同步功能。

## 开发与构建

使用 Node.js 24。执行 `npm ci` 安装依赖，`npm run dev` 启动开发服务，`npm run build` 生成 `dist`。部署静态网站时使用 `dist` 的全部内容。

当前页面入口是 `src/textbook-main.ts`。`scripts/review-airspace-regression.js` 是原页与立体空间流程的浏览器检查之一，可执行：

```powershell
node scripts/run-visual-review.mjs scripts/review-airspace-regression.js
```

该脚本默认连接 `http://127.0.0.1:5173`，使用本机 Chrome；截图和记录写入 `output/playwright/`。可用环境变量 `REVIEW_BROWSER=msedge`、`REVIEW_BASE_URL` 和 `REVIEW_OUTPUT` 指定浏览器、地址与结果路径。单项脚本通过不能代替所有模型、状态、设备和离线包验收，当前结果统一记录在 `docs/验收记录.md`。

`npm test` 验证科学模型和保留的学习逻辑。`npm run test:e2e` 运行 `tests/current-e2e` 的9条整册用户流程，默认自动启动5183本地开发服务；可用 `REVIEW_BASE_URL=http://127.0.0.1:4175` 指向正式构建。每条用例保存实际脚本及样式指纹，`node scripts/summarize-current-e2e.mjs` 汇总并核对正式构建。旧 `tests/e2e` 和旧入口仅保留作开发参考，不参与当前E2E命令。

构建后，PowerShell 执行 `./scripts/package.ps1` 生成离线包、源工程包和静态网站包。打包前更新当前验收记录与 `docs/verification/current-build.json`；打包后执行 `scripts/verify-delivery.py` 核对源码、构建、归档及本地4173服务，结果保存到 `release/交付一致性.json`。

- `src/textbook-models-*.ts`：天文、大气、水、地貌、土壤、灾害与地理信息技术的几何模型。
- `src/model.ts`：海陆风冷热、气压和环流的统一科学状态。
- `src/textbook-model-input.ts`：模型本体的选择、重放、昼夜转盘与过程轨道契约；书本适配层负责实际射线命中、抓取偏移及指针捕获。
- `src/textbook-haze-model.ts`、`textbook-haze-world.ts`：污染存量、后续排放和移出范围的纯计算，共用示踪及可点选的烟囱、风旗。
- `src/textbook-delta-model.ts`、`textbook-delta-world.ts`：连续搬运、减速沉降、沉积地形及不等长弯曲分流。
- `src/textbook-soil-sorting-model.ts`、`textbook-soil-sorting-world.ts`：成土因素第五项的固定颗粒池、山坡水流及同源 SVG。
- `src/textbook-quake-model.ts`、`textbook-quake-world.ts`：P/S 波到达、探测处理、通信预警与远近场对照，共用计算和原生 SVG。
- `src/textbook-karst-model.ts`、`textbook-karst-world.ts`：闭合岩体的裂隙溶蚀、同源地表雨水与可拖动水滴。
- `src/textbook-soil-profile-model.ts`、`textbook-soil-profile-world.ts`：六层剖面、固定物质池、淋溶与淀积，以及层体点击和水滴拖动。
- `src/textbook-disaster-chain-model.ts`、`textbook-disaster-chain-world.ts`：沿海地下水与地层变化、滑坡堵河与选定溃决过程，实体重放与同源 SVG。
- `src/textbook-salinity-model.ts`、`textbook-salinity-world.ts`：同初始海水、固定溶解盐与有限水量交换，实体重放、水滴拖动及同源 SVG。
- `src/textbook-coastal-process-model.ts`、`textbook-coastal-process-world.ts`：海蚀崖凹蚀、有限岩块崩落与原位平台，纸签拖动及同源 SVG。
- `src/textbook-strata-model.ts`、`textbook-strata-world.ts`：原图六层、九个化石与两组对应，实体点选、间距纸签及同源 SVG。
- `src/textbook-landslide-model.ts`、`textbook-landslide-world.ts`：连贯滑体与有限含水碎屑的独立过程，实体重放、进度手柄及同源 SVG。
- `src/textbook-current-model.ts`、`textbook-current-world.ts`：十二个固定水体的连续迁移、起点与末位置对照、波浪往复参照及同源 SVG。
- `src/textbook-solar-heating-model.ts`、`textbook-solar-heating-world.ts`：剖面房屋、集热器、共享储存池与闭合水路，光与水分别示踪及同源 SVG。
- `src/textbook-typhoon-model.ts`、`textbook-typhoon-world.ts`：保留真实眼洞的成熟台风剖面、四类气流的连续显现、实体定位与同源 SVG。
- `src/textbook-temperature-model.ts`、`textbook-temperature-world.ts`：固定温度曲线、连续深度探针与切片、同步旁注及同源SVG。
- `src/textbook-slope-model.ts`、`textbook-slope-world.ts`：原图主要点线约束的教学地形、贴地等高线和6.4米高差放大对照。
- `src/textbook-recovery-model.ts`、`textbook-recovery-world.ts`：玉树搜救与北川异地恢复两个独立案例的连续观察。
- `src/textbook-astronomy-model.ts`：太阳系生产坐标、内部圈层抽层配置与同源SVG。
- `src/textbook-flat-model.ts`、`textbook-flat-*.ts`、`textbook-effects.ts`：原生SVG二维演示与对应状态。
- `public/textbook/`：从原教材 PDF 转换的本地页面及封面影像。

`src/main.ts`、`scene.ts`、`paper.ts`、`state.ts` 等早期三课模块未作为当前网页入口。教师用法、逐项覆盖、来源和验证范围见 `docs/`。教材及参考项目的权利归原权利人；交付包包含教材页面影像与参考引擎，来源记录不表示已取得公开再分发许可。
